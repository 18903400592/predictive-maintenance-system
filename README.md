# Predictive Maintenance System

A manufacturing data analysis and monitoring project.

The project uses machine and production data to explore equipment
failures and build a simple predictive maintenance workflow.

## Project Overview

The project is based on the AI4I 2020 Predictive Maintenance Dataset.

It currently focuses on:

- exploring machine and production data
- identifying patterns related to equipment failure
- storing production data in PostgreSQL
- providing a simple backend API
- displaying the data through a React frontend

## Tech Stack

- Python
- Pandas
- Scikit-learn
- FastAPI
- React
- PostgreSQL
- SQL
- HTML / CSS
- Git

## How It Works

The current workflow is:

Manufacturing Data
        ↓
   PostgreSQL
        ↓
   FastAPI API
        ↓
   React Frontend
        ↓
Monitoring & Analysis
